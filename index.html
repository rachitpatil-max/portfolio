CASE-00 Active

Shadow AI Detection System

MSc thesis · privacy-preserving detection for AI chat tools

A zero-persistence system that flags data-leakage risk and unsafe or jailbreak-style prompts in AI chat tools — without ever storing the raw text someone typed. It runs as a Chrome extension in front of a FastAPI backend, with an aggregate monitoring dashboard on the other end.

The detection engine works in layers: regex and heuristic rules first, then spaCy for named-entity recognition, a seven-algorithm classical ML comparison suite, and finally a bidirectional LSTM with multiple task heads, built in PyTorch.

Chrome Extension (MV3) FastAPI spaCy NER PyTorch BiLSTM scikit-learn
